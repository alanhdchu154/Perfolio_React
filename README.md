# Alan Portfolio

Alan's public portfolio and career-positioning site.

## Read First

- `AGENTS.md` - project lead and public-positioning rules.
- `CLAUDE.md` - Claude-facing local notes.
- Use Central Umi's `portfolio-career-market-router` skill before recruiter,
  job-market, resume, opportunity-fit, public case-study, or positioning work.

## Common Commands

```bash
npm start
npm run build
CI=true npm test -- --watchAll=false
```

## Boundaries

- Keep confidential enterprise details abstract and public-safe.
- Prefer senior SDE / data systems / applied-AI positioning over generic
  portfolio copy.
- Do not add new routing or heavy framework changes unless the active portfolio
  task needs them.
